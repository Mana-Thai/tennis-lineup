# 伝統テニス大会 オーダー(メンバー用閲覧ページ)

第44回 チョンブリー県内クラブ・同好会対抗 伝統テニス大会のチームオーダーを、
メンバーがログインなしで見るためのページです(GitHub Pages)。

- 管理者が管理者版で作った「閲覧リンク」を開くと表示されます
- オーダーの内容はリンクの `#` 以降に入っていて、このリポジトリやサーバーには保存されません
- 年齢・レベルなど管理者だけの情報はリンクに含まれません

`index.html` は `Mana-Thai/line-ai-chatbot` の `tennis-lineup/build.py` で生成したものです
(`dist/viewer/index.html`)。直接編集せず、元リポジトリで作り直してコピーしてください。
